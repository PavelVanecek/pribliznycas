pribliznycas.cz website
=======================

How to install
--------------

    git clone https://github.com/PavelVanecek/pribliznycas.git pribliznycas
    cd pribliznycas
    npm install

Requires Node.js 20.19 or newer.

How to develop
--------------

    npm start

Starts the Vite dev server with live reload.

How to build
------------

    npm run build

The site is written to `build/`, with minified HTML, CSS and JS. `npm run preview` serves the built output locally.
